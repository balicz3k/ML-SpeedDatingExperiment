# ML-SpeedDatingExperiment

## Dane

Dane nie są przechowywane w repozytorium. Pochodzą z Kaggle:
[Speed Dating Experiment](https://www.kaggle.com/datasets/annavictoria/speed-dating-experiment).

Pobranie:
- automatycznie – pierwszy notatnik (`1_speed_dating_experiment-primary_analysis.ipynb`) pobiera zbiór przez `kagglehub`, albo
- ręcznie – pobierz archiwum ze strony Kaggle i rozpakuj `Speed Dating Data.csv` do katalogu `data/`.

Pliki `data/meetings*.csv` tworzy notatnik `2_preparing_data.ipynb` (podział na zbiór treningowy i testowy).
Notatniki uruchamiaj po kolei: 1 → 2 → 3 → 4.
